# Support

## Public Support Scope

Use the GitHub issue forms for:

- reproducible defects in the public Core package or CLI;
- questions about documented public contracts and synthetic examples;
- bounded feature proposals for the shared repository.

Include the package version, operating system, Python version, exact command, expected
result, actual diagnostic, and a minimal synthetic reproduction. Support is best-effort;
no response-time or resolution-time SLA is provided.

## Out Of Scope

Public issues must not contain real PDFs, parsed paper text, Evidence quotes, research
notes, private workspace exports, credentials, local absolute paths, or institution-only
access details. Private workspace migration, recovery of user research data, and scientific
judgment are not public Core support services.

Report suspected vulnerabilities and exposed credentials privately as described in
[`SECURITY.md`](SECURITY.md). Do not use a public issue for security-sensitive material.
